# Руководство пользователя — Qwen3-TTS UI

## Быстрый старт

1. Запустить `start.bat` в папке проекта
2. Браузер откроется автоматически на `http://127.0.0.1:8001`
3. При первом запуске модель загружается ~60 секунд — подождать
4. Вставить текст, выбрать голос, нажать **Запустить синтез**

---

## Интерфейс — блок за блоком

### ТЕКСТ

Два способа ввода:
- **Вставить напрямую** — кликнуть в поле и набрать или вставить текст (Ctrl+V)
- **Загрузить файл** — перетащить `.txt` файл в поле или кликнуть по нему

Рекомендуемый объём: до 500–600 слов за один запуск. Длиннее — синтез будет идти
несколько минут и результат может быть нестабильным в конце.

---

### ГОЛОС

Список карточек с доступными голосами из папки `voices/`.
Рядом с каждым — кнопка воспроизведения (►) для прослушивания референса.

**Как добавить новый голос:**
Положить WAV-файл в папку `voices/` и перезапустить сервер.
Требования к файлу:
- Формат: WAV, моно или стерео
- Длина: 5–30 секунд чистой речи без музыки и шума
- Качество: чем чище запись, тем точнее клонирование голоса

**Важно понимать:** модель не генерирует голос из воздуха —
она клонирует тембр и манеру речи из референсного файла.
Если референс женский — голос будет женским. Хотите мужской — нужен мужской WAV.

### ПАРАМЕТРЫ

#### Язык

Выбор языка синтеза. Влияет на произношение и интонацию.

| Значение | Когда использовать |
|----------|--------------------|
| **Russian** | Русский текст — основной режим |
| **Auto** | Текст смешанный (русский + английские термины) |
| **English** | Полностью английский текст |
| **Chinese** | Китайский текст |

Пример для Auto: *«Сервис работает через REST API и возвращает JSON-ответ»*
— модель сама определит, что `REST API` и `JSON` нужно читать по-английски.

---

#### Выразительность (temperature: 0.5 – 1.0)

Управляет случайностью интонации. Чем выше — тем живее и разнообразнее звучание,
но выше риск нестабильности.

| Значение | Результат | Когда использовать |
|----------|-----------|--------------------|
| **0.5 – 0.6** | Ровная, спокойная речь | Деловые тексты, инструкции, новости |
| **0.7 – 0.8** | Умеренная выразительность | Художественная проза, описания |
| **0.9** | Живая речь, заметные интонации | Диалоги, эмоциональные сцены |
| **1.0** | Максимальная экспрессия | Короткие эмоциональные фразы |

**Пример низкой выразительности (0.5):**
> *«Порядок установки: скачайте архив, распакуйте, запустите setup.exe,
> следуйте инструкциям мастера установки.»*
> — Монотонное перечисление, здесь высокая выразительность будет лишней.

**Пример высокой выразительности (0.9):**
> *«— Ты уходишь? — спросила она тихо, почти шёпотом.
> Он остановился у двери, не обернувшись. — Да. Прости.»*
> — Диалог требует интонационных перепадов.

---

#### Чистота звука (repetition_penalty: 1.0 – 1.3)

Штраф за повторяющиеся аудио-токены. Помогает избежать артефактов —
зацикливания, странных повторов звуков, «заикания» модели.

| Значение | Результат | Когда использовать |
|----------|-----------|--------------------|
| **1.0** | Без штрафа | Короткие тексты, если артефактов нет |
| **1.05** | Лёгкий штраф (по умолчанию) | Большинство случаев |
| **1.1 – 1.2** | Заметный штраф | Длинные тексты, если слышны повторы |
| **1.3** | Сильный штраф | Проблемные места, но может смягчить интонацию |

**Когда поднимать:** если в результате слышите, что одна фраза или звук
повторяется несколько раз подряд — увеличьте до 1.1 или 1.15.

---

#### Стабильность (subtalker_temperature: 0.5 – 1.0)

Температура внутреннего субмодуля, который генерирует финальные аудио-токены.
Работает в паре с Выразительностью, но влияет на другой уровень.

Низкое значение = более предсказуемый, ровный звук.
Высокое значение = больше вариативности в тембре, но выше риск артефактов.

| Значение | Результат | Когда использовать |
|----------|-----------|--------------------|
| **0.5 – 0.6** | Очень стабильный звук | Если слышны хрипы или нестабильность тембра |
| **0.7 – 0.8** | Баланс | Длинные тексты, проза |
| **0.9** | По умолчанию | Стандартный режим |

**Рекомендация для длинных текстов:** снизить до 0.7 — к концу длинного синтеза
модель меньше «устаёт» и тембр остаётся стабильнее.

### СИНТЕЗ

Кнопка **Запустить синтез** — отправляет текст на сервер.
Сервер сразу возвращает `job_id` и начинает генерацию в фоне.

**Прогресс-бар** обновляется каждые 2 секунды.

**Время ожидания:**
- Короткий абзац (50–100 слов): ~15–30 секунд
- Страница текста (~300 слов): ~60–90 секунд
- Длинный фрагмент (~500 слов): ~2–3 минуты

После завершения появляется плеер — можно сразу прослушать.
Кнопка **Скачать** сохраняет WAV на ваш компьютер.

## config.json — полный разбор

Файл `config.json` хранит настройки по умолчанию. Значения из него подставляются
при запуске сервера. UI-слайдеры переопределяют их для каждого запроса.

```json
{
  "model": "Qwen/Qwen3-TTS-12Hz-1.7B-Base",
  "ref_audio": "G:\\AI\\_MY_PROGRAMMING_3\\VOICE-OVE-RECORDING\\voices\\eugene.wav",
  "language": "Russian",
  "output_dir": "output",
  "temperature": 0.9,
  "repetition_penalty": 1.05,
  "subtalker_temperature": 0.9,
  "subtalker_top_k": 50,
  "subtalker_top_p": 1.0,
  "max_new_tokens": 2048
}
```

| Параметр | Что делает |
|----------|------------|
| `model` | Имя модели на HuggingFace. Не менять без необходимости. |
| `ref_audio` | Путь к WAV-файлу голоса по умолчанию. Используется если UI не передаёт другой. |
| `language` | Язык синтеза по умолчанию. |
| `output_dir` | Папка для сохранения результатов. |
| `temperature` | Начальное значение слайдера «Выразительность». |
| `repetition_penalty` | Начальное значение слайдера «Чистота звука». |
| `subtalker_temperature` | Начальное значение слайдера «Стабильность». |
| `subtalker_top_k` | Ограничение выборки субмодуля (топ-K токенов). Менять редко. |
| `subtalker_top_p` | Nucleus sampling субмодуля. Менять редко. |
| `max_new_tokens` | Максимальная длина генерации в токенах. 2048 ≈ ~40 сек аудио. Увеличить для очень длинных текстов. |

## Рецепты для разных типов текста

### Художественная проза — нейтральное повествование

```
Выразительность:  0.75
Чистота звука:    1.05
Стабильность:     0.75
Язык:             Russian
```

> *«Дом стоял на краю деревни. Старые яблони в саду давно не плодоносили,
> но никто их не рубил — привыкли. По вечерам в окне горел свет,
> и дым из трубы тянулся прямо вверх, в серое небо.»*

---

### Диалог с эмоциями

```
Выразительность:  0.90
Чистота звука:    1.05
Стабильность:     0.90
Язык:             Russian
```

> *«— Я устала, — сказала она, не поворачиваясь.
> — Знаю.
> — Нет, ты не знаешь. Ты никогда здесь не был.
> Он промолчал. Возразить было нечего.»*

---

### Длинный текст, важна стабильность

```
Выразительность:  0.75
Чистота звука:    1.10
Стабильность:     0.65
Язык:             Russian
```

Снижение `Стабильности` и повышение `Чистоты звука` помогают избежать
деградации голоса к концу длинного фрагмента.

---

### Текст с иностранными словами

```
Выразительность:  0.80
Чистота звука:    1.05
Стабильность:     0.80
Язык:             Auto
```

> *«Система построена на микросервисной архитектуре.
> Каждый сервис общается через gRPC и публикует метрики в Prometheus.
> Dashboard собран на Grafana.»*

## Частые вопросы

**Голос звучит монотонно** — поднять Выразительность до 0.9–1.0.

**Слышны хрипы или нестабильность тембра** — снизить Стабильность до 0.6–0.7.

**Модель повторяет одну фразу несколько раз** — поднять Чистоту звука до 1.1–1.15.

**Ударение на неправильном слоге** — к сожалению, это ограничение модели.
Попробуйте переформулировать слово или разбить предложение иначе.
Также помогает режим `Auto` вместо `Russian` — иногда даёт другой результат.

**Синтез завис** — проверить, что сервер запущен через `start.bat`,
а не системным Python. Перезапустить при необходимости.
